# Documentation (`docs/`)

Project documentation for **Creator Intelligence** — the DSCI351 recommender system that suggests Instagram content strategies to influencers.

**New to the repo?** Start with [How_It_Works.md](How_It_Works.md), then [Pipeline.md](Pipeline.md) for how to run the code.
