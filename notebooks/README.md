# Notebooks (`notebooks/`)

Jupyter notebooks for data extraction, exploration, and interactive pipeline runs. The **canonical** notebook for grading is `Recommender Pipeline and Model Development.ipynb`; the others are earlier prototypes kept as the development audit trail.

**Prefer scripts for reproduction:** `python scripts/run_pipeline.py` produces the same end-to-end outputs without manual notebook steps. See [docs/Pipeline.md](../docs/Pipeline.md).

---

## Notebook guide

| Notebook | Status | Purpose |
|----------|--------|---------|
| **`Recommender Pipeline and Model Development.ipynb`** | **Primary** | Notebook-to-production walkthrough: shows the development map, final module code, feature checks, all 5 models, metrics, and saved artifacts |
| `Data_Extraction.ipynb` | Development audit trail | Colab workflow used to discover Drive paths, inspect the dataset, extract post metadata from `posts_info.zip`, and build subsets |
| `Cleaned Up Notebook.ipynb` | Development audit trail | Early EDA, strategy labels, engagement scoring, baselines, and CF prototyping before code moved to `src/` |

## When to use which

### `Recommender Pipeline and Model Development.ipynb` (recommended for demos)

Use when you want to:

- Step through the pipeline cell-by-cell for a presentation
- Inspect intermediate DataFrames (posts, strategies, interaction matrix)
- Run on Colab with Google Drive paths

Imports from `src/` — logic lives in modules, not duplicated in the notebook.

This notebook is intentionally written as a bridge from prototype to final repo:

- It maps the legacy notebooks to the final modules.
- It displays representative source code from the final modules with `inspect.getsource(...)`.
- It runs the pieces step by step before running the full production pipeline.
- It proves the final artifacts are generated by the same code used in `scripts/run_pipeline.py`.

### `Data_Extraction.ipynb`

Use when you need to:

- Extract a sample of post metadata from the full archive on Colab
- Produce `posts_base_*.parquet` for `--posts-parquet` or local analysis

After extraction, run the pipeline from the repo root:

```bash
python scripts/run_pipeline.py --posts-parquet path/to/posts_base_10000.parquet
```

### `Cleaned Up Notebook.ipynb`

Historical notebook from early development. Superseded by `src/` modules and `Recommender Pipeline and Model Development.ipynb`. Kept for audit trail only.

## Environment setup

From the repo root:

```bash
pip install -r requirements.txt
jupyter notebook "notebooks/Recommender Pipeline and Model Development.ipynb"
```

For large data, open in **Google Colab** and follow [docs/Colab_Setup.md](../docs/Colab_Setup.md).
